Explorer — static prototype

The same class view the live site serves from Streamlit, rendered with no server at all. Every page here is a plain file: the drawing code is the Explorer's own canvas applets, and the mathematics arrived as JSON that was computed once, at build time.

Prototype scope: only the primes below were built. The real port would ship one shard per prime up to 8191 — 1,026 files, about 190 MB gzipped in total.
